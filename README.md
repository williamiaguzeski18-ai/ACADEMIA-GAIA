# ACADEMIA GAIA

Repositório exclusivo para a **estrutura pedagógica versionada** da Academia GAIA: cursos técnicos, metodologia, exercícios e avaliações para os agentes **00–03**.

> **Estado:** estrutura inicial em elaboração; cursos não homologados e competências não avaliadas. Este repositório é independente do código do produto [GAIA RAG & KNOWLEDGE](https://github.com/williamiaguzeski18-ai/rag-knowledge).

## Organização prevista
- `academia/BASE_COMUM/` — fundamentos transversais.
- `academia/AGENTES/` — quatro especializações.
- `academia/METODOLOGIA/` — GAIA-EDU, fontes, avaliação e carga.
- `academia/MODELOS/` — modelos de aula, exercício e registro.
- `academia/INDICES/` — inventário e mapeamento para catálogo futuro no Notion.

Cada agente possui `CURSO/`, `EVOLUCAO/` e `PROJETO/`. A separação entre formação e trabalho técnico é obrigatória.

**Governança:** nenhum arquivo de curso concede autorização para conectar contas, mover documentos, escrever memórias, alterar código de projetos, fazer merge ou implantar serviços. Todo material deve ter origem, versão, estado e revisão humana.

**Próximo passo:** revisão da proposta pedagógica em uma branch isolada. Não há integração automática à `main`.
